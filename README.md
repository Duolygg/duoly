# Duoly

Private production application owned by the Duolygg organization.

Stack: Astro, TypeScript, selected React islands, Supabase, Vercel, PostHog, and Resend.

The production foundation is being established in a reviewed setup branch. No customer functionality or production launch is implied by this bootstrap.

## Design reference

The separate design sandbox is https://github.com/duoly-admin/duoly at reference commit `7f0299fe35d4ebbba1ebea36f1ecd46bab5f0280`.

Its screens are visual references. Its Next.js implementation, sample data, and backend assumptions are not production specifications. Do not automatically synchronize the repositories.

## Working arrangement

Use individual GitHub accounts, short-lived issue branches, independent review, and squash-merged pull requests. Do not commit credentials or customer data. Production changes and paid service upgrades require owner approval.

The first bootstrap commit is the documented exception needed to establish the default branch before opening the foundation pull request.
