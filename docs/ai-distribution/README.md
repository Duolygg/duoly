## Scope and release gates

V1 tools are public discovery, quotes, availability and a Duoly site link. No login is needed for tools. Payment and final booking remain on duoly.gg. Social voice sessions are excluded. No account linking, payment execution, reservation writes or booking history are promised. The MCP implementation is a separate PR and is not certified by these drafts.

Before publication, the owner must confirm the legal submitting entity and named contact, choose the allowed countries and languages, approve assets and legal wording, obtain commerce classification, and resolve platform-specific public-data reviewer access. Planned documentation URLs must be deployed and tested. Tool examples use live discovery rather than fabricated IDs. Actual schemas, quotas and logging must be reconciled with the server release.
