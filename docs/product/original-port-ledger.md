# Original repo port ledger

Goal: use up everything in the original repo (`duoly-admin/duoly@7f0299f`) so nobody has to look back there. Every original screen (`src/design-reference/components/**`), library (`lib/*.js`) and API route (`app/api/**`) is listed once below. An item is **done** only when it is (1) ported to Astro (page plus React island or native component, server code in `src/server`, data in Supabase) and (2) fully functional on duoly.gg with real data. Sample data, "coming soon" panels and closed forms don't count.

**Done means the original screen is on duoly.gg.** A row is ✅ only when the original component (or a faithful port of it, same layout and copy) is what users see and it runs on the real backend. A working backend behind a stand-in screen is 🟡 or 🔴, never ✅. The live customer dashboard, order room and teammate dashboard now use their original screens. `OrderDesk`, `CustomerOrderRoom` and their legacy fixtures remain unused by production pages for the separate cleanup chunk. `LoginCard` remains intentionally as the `/login` landing for email links and sign-in-required redirects; Home uses its original sign-in popup.

Reuse what was already worked out (screens, copy, product rules, edge cases), but don't copy blindly: where we already have a better implementation (Supabase RPCs instead of JSON files, Stripe, Supabase Auth), keep ours and use the original only as the behaviour checklist.

Status: ✅ done · 🟡 partial (what's missing is stated) · ⬜ not started · 🔒 another agent is on it · ➖ intentionally not ported (reason given)

Original backend source for reference: `docs/source-archives/duoly-next-backend-7f0299f.tar.gz`. Per-file notes: `backend-salvage.md`.
